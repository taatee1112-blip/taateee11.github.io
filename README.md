# GROCERY PRO - ระบบจัดการสต็อกร้านขายของชำและโชห่วย (Grocery Store Stock Management)

ระบบจัดการคลังสต็อกสินค้าอุปโภคบริโภคสำหรับร้านขายของชำ, ร้านโชห่วย และร้านมินิมาร์ท ออกแบบมาเพื่อการทำงานที่รวดเร็ว ข้อมูลถูกบันทึกบนเครื่องของคุณโดยตรงอย่างปลอดภัย ไม่ต้องติดตั้งโปรแกรมหรือเซิร์ฟเวอร์เสริมใดๆ

---

## 🚀 วิธีเปิดใช้งาน

คุณสามารถเลือกเปิดได้ 2 วิธีง่ายๆ:

### วิธีที่ 1: ดับเบิ้ลคลิกเปิดผ่านเบราว์เซอร์ทันที (สะดวกที่สุด)
* ดับเบิ้ลคลิกที่ไฟล์ **`start.bat`** หรือเปิดไฟล์ **`index.html`** ด้วย Google Chrome หรือ Microsoft Edge ได้ทันที

### วิธีที่ 2: เปิดผ่าน Local Server (แนะนำหากต้องการใช้กล้องสแกนบาร์โค้ด)
* ดับเบิ้ลคลิกที่ไฟล์ **`start-server.bat`** 
* ระบบจะเปิดหน้าเว็บที่ `http://localhost:8080/` ให้อัตโนมัติ

## ✨ ฟังก์ชันและความสามารถของระบบ

1. **📊 ภาพรวมคลังสินค้า (Dashboard):**
   * แสดงจำนวน SKU สินค้าทั้งหมด, ยอดชิ้นรวมคงเหลือ, และมูลค่าต้นทุนสินค้าในคลัง
   * การ์ดแจ้งเตือนสินค้าใกล้หมด (Low Stock) และสินค้าหมดสต็อก (Out of Stock)
   * กราฟสรุปการเคลื่อนไหวรับเข้า-เบิกออกย้อนหลัง 7 วัน (Chart.js)
   * กราฟสัดส่วนหมวดหมู่สินค้า
   * ตารางสินค้าที่ต้องสั่งซื้อเร่งด่วน

2. **📦 จัดการรายการสินค้าและสต็อก (Inventory):**
   * เพิ่ม แก้ไข ลบ รายการสินค้า พร้อมระบบรันรหัส SKU อัตโนมัติ
   * กำหนดตำแหน่งจัดเก็บ (Shelf/Location เช่น ชั้น A1-02) เพื่อความสะดวกในการหยิบของ
   * ระบุราคาต้นทุน, ราคาขาย และจุดเตือนสต็อกขั้นต่ำ (Min Stock)
   * ค้นหาสินค้าแบบ Real-time ด้วยชื่อ, SKU, บาร์โค้ด หรือตำแหน่งชั้นวาง
   * กรองสินค้าตามหมวดหมู่ หรือสถานะสต็อก (ปกติ, ใกล้หมด, หมดสต็อก)
   * ปุ่มลัดรับเข้า-เบิกออกด่วนจากตารางได้ทันที

3. **📥 รับสินค้าเข้า (Stock In):**
   * เลือกสินค้า ระบุจำนวนที่รับเข้า และราคาต้นทุนต่อหน่วยล่าสุด
   * บันทึกเลขที่ใบส่งของ / เลขที่ PO, ชื่อผู้รับสินค้า และหมายเหตุ
   * อัปเดตยอดสต็อกและต้นทุนคงเหลืออัตโนมัติ

4. **📤 เบิกสินค้าออก (Stock Out):**
   * ตรวจสอบยอดสต็อกก่อนเบิก ป้องกันการเบิกเกินสต็อกที่มีอยู่
   * ระบุวัตถุประสงค์ (ขาย, เสียหาย, เบิกใช้ภายใน, โอนย้าย)
   * บันทึกเลขที่ใบสั่งซื้อ/Order และชื่อผู้เบิก
   * ระบบแจ้งเตือนทันทีหากยอดคงเหลือลดลงต่ำกว่าจุดปลอดภัย

5. **📷 สแกนเนอร์บาร์โค้ด / QR Code:**
   * รองรับการใช้กล้องเว็บแคมสแกนสินค้า หรือพิมพ์รหัสค้นหาด้วยตนเอง
   * มีเสียง Beep สังเคราะห์แจ้งเตือนเมื่อสแกนพบสินค้า พร้อมเมนูลัดสำหรับรับเข้า/เบิกออกทันที

6. **📋 ประวัติการทำรายการ (Transaction Logs):**
   * บันทึกทุกความเคลื่อนไหว (รับเข้า, เบิกออก, สต็อกเริ่มต้น) พร้อมวันเวลาที่ละเอียด
   * บันทึกยอดสต็อกก่อนทำรายการ และยอดสต็อกคงเหลือหลังทำรายการ
   * คัดกรองตามประเภทรายการได้

7. **💾 สำรองข้อมูลและนำเข้า (Data Backup & Restore):**
   * ส่งออกข้อมูลสินค้าเป็นไฟล์ **Excel / CSV** (รองรับภาษาไทย UTF-8)
   * ส่งออกประวัติการรับเข้า-เบิกออกเป็นไฟล์ **CSV**
   * สำรองข้อมูลทั้งระบบเก็บไว้เป็นไฟล์ **JSON** และสามารถนำกลับมากู้คืนได้ตลอดเวลา
   * มีปุ่มโหลดชุดข้อมูลตัวอย่าง (Demo Data) สำหรับทดสอบระบบ

8. **🖨️ พิมพ์รายงานสต็อก (Print Report):**
   * กดพิมพ์รายงานสรุปสต็อกสินค้าคงเหลือและมูลค่ารวม จัดหน้ากระดาษพร้อมพิมพ์ทันที
